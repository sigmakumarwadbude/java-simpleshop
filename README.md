# SimpleShop

A modern e-commerce application built with Java 21, Spring Boot 3, Angular 22, PostgreSQL, and Docker.

## Tech Stack

### Backend
- Java 21
- Spring Boot 3
- Spring Security
- Spring Data JPA
- PostgreSQL
- Maven

### Frontend
- Angular 22
- Standalone Components
- Signals
- Angular Material
- Tailwind CSS

### DevOps
- Docker
- Docker Compose
- GitHub Actions

---

## Features

- Product Catalog
- Product Details
- Search Products
- Shopping Cart
- Authentication
- Orders
- Admin Dashboard
